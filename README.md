# Academic Research Site

Academic and research portfolio for Hari Krishna Joshi, built with Next.js and Tailwind CSS.

Hosted at [harijoshi07.github.io/academic](https://harijoshi07.github.io/academic/).

## Local Development

```bash
npm install
npm run dev
```

Visit [http://localhost:3000/academic](http://localhost:3000/academic).

## Build & Static Export

```bash
npm run build
```

The static output is generated in `./out` with `basePath: '/academic'`.

## Deployment

Deployments to GitHub Pages run automatically via GitHub Actions upon push to the `main` branch.
